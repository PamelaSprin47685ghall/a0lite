# Dependency set for the Flatpak build.
#
# Derived from ../requirements.txt with the local-inference stack removed:
# every model runs on the bundled Ollama server instead.
#
# Removed on purpose:
#   faiss-cpu                  vector index replaced by an Ollama-backed store
#   sentence-transformers      embeddings come from Ollama /api/embed
#   torch, torchvision         only needed by sentence-transformers and whisper
#   triton, nvidia-*           GPU kernels for torch, unused without torch
#   onnxruntime                TTS and OCR now run on Ollama
#   kokoro, misaki, spacy      local TTS stack replaced by Ollama speech
#   openai-whisper, numba      local STT stack replaced by Ollama transcription
#   unstructured[all-docs]     document parsing moves to Ollama vision models
#
# Keep the two-runtime note from the upstream image: this file installs the
# framework runtime only. Task code shares the same interpreter.
#
# Everything resolves to a wheel on Python 3.14 except flask-basicauth and
# crontab, which ship as pure-Python sdists only. Both build without a C
# compiler, so the sandbox needs no toolchain.
#
# `unstructured` declares `numpy<2`, but no numpy 1.x wheel exists for cp314.
# The bound is a compatibility guard, not a requirement: the partitioners this
# build uses run on numpy 2, which flatpak/numpy-override.txt relaxes.
# These two ship without wheels and build from a pure-Python sdist. They are
# installed first, by themselves, so the wheel-only pass below never reaches a
# source build.
